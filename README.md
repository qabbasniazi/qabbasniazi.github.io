# Dr. Qaiser Abbas — Academic Website

Responsive static website based on the CV provided. No build tools or dependencies are needed.

## Preview locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a GitHub repository, e.g. `qaiser-abbas-website`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish; the live URL appears in Settings → Pages.

## Notes
- Personal mobile number and birth date were omitted from the public site.
- Publications shown are a selection, not the complete CV bibliography. Verify metadata before publishing.
- Google Fonts is optional; system font fallbacks are included.
